# 江趙府婚禮流程・長輩版

2026.12.06 台北漢來大飯店　文定（水晶 E 廳）＋喜宴（3 樓鉑金 C 廳）

| 檔案 | 給誰看 |
| --- | --- |
| `bride.html` | 女方爸爸、媽媽 |
| `groom.html` | 男方爸爸、媽媽 |

兩個檔案各自獨立，功能相同，只顯示自己那一方的流程。

## 功能

- 提早準備清單（預設收起，可打勾；勾選紀錄只存在該支手機）
- 流程由早到晚：梳化 → 文定 → 彩排 → 喜宴
- 點項目標題展開說明與要做的事；個人負責的項目標題旁有「爸爸／媽媽」標籤
- 12/06 當天自動標示「現在」、已過項目反灰、已結束的大項目自動收起
- 頂端綠色條可點擊，直接跳到目前項目或下一件要做的事

## 測試

網址後加 `#test`，頁面底部會出現「模擬當天時間」。

```
https://jhctw.github.io/wedding/wedding-parents/bride.html#test
```

網址後加 `#live`，會把「今天」當成婚禮當天，依手機的真實時間顯示「現在」、反灰與自動收起，適合實際走一遍。

## 修改流程

流程資料在檔案內 `<script>` 的 `PHASES`（各段時間、說明、雙方要做的事）與 `PREP`（提早準備清單）。
兩個檔案的資料相同，修改時兩個都要改。

## 部署

放進 GitHub repo 後，在 Settings → Pages 選擇分支即可。頁面已加 `noindex`，不會被搜尋引擎收錄；
免費版 GitHub Pages 需為公開 repo，原始碼任何人都看得到。
